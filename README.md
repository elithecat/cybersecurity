# Cybersecurity in 2026

Materials for a talk to professors by Alyssa Bilinski (Brown University).

- `cybersecurity_2026_briefing.pdf`: the slides for presenting, one page per click.
- `cybersecurity_2026_briefing_handout.pdf`: the slides for reading, one page per slide.
- `security_checklist.pdf`: a one-page checklist of steps, in 3 levels of urgency.
